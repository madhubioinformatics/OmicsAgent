✦ Installation

Up and running in 60 seconds

Three install paths — choose what fits your workflow.

1 Prerequisites

Check your Python version and install system dependencies

# Python 3.10+ required
python3 --version
Python 3.12.3  ✓

# Conda (recommended)
conda create -n omics-agent python=3.11
conda activate omics-agent

2 Clone & Install

Clone the repository and install Python dependencies

git clone https://github.com/madhubioinformatics/omics-agent
cd omics-agent
pip install -r requirements.txt
Successfully installed 12 packages ✓

3 Set API Key

Add your Anthropic API key for natural language routing

# Get key at console.anthropic.com
export ANTHROPIC_API_KEY="sk-ant-..."

# Or add to .env file
echo 'ANTHROPIC_API_KEY=sk-ant-...' >> .env

4 Run Demo

Execute all 15 skills on PBMC demo data to verify everything works

# Generate PBMC demo data first
python3 data/pbmc_demo_generator.py

# Run all 15 skills
python3 omics_agent.py --demo
15/15 skills ✓  50 figures  79s

🐳 Docker (isolated, no dependency conflicts)

Recommended for HPC or when you want complete environment isolation

# Build image
docker build -t omics-agent .

# Run with your data mounted
docker run -v $(pwd)/data:/app/data \
  -e ANTHROPIC_API_KEY=$ANTHROPIC_API_KEY \
  omics-agent python3 omics_agent.py --demo

# Interactive chat inside container
docker run -it omics-agent python3 omics_agent.py --chat

Natural language prompt
